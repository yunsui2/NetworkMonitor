# Network Monitor

## 项目简介

Network Monitor 是一个桌面网络流量监控工具。

用于实时显示电脑网络使用情况，包括：

* 当前下载速度
* 当前上传速度
* 今日流量统计
* 本月流量统计
* 网络连接状态

软件定位为轻量级桌面监控工具。

目标是提供比 Windows 任务管理器更直观、更美观的网络监控体验。

---

## 项目特点

* 实时网速显示
* 流量历史统计
* 现代化界面
* 资源占用低
* 长时间后台运行

---

## 使用场景

* 下载文件时观察速度
* 查看每日流量消耗
* 查看每月流量消耗
* 长期开启作为网络监控面板
